# ISEE Middle Level Learning Lab

An independent English-language ISEE Middle Level learning tool, designed as an installable offline PWA.

**Deployment is incomplete until `index.html`, `icon-192.png` and `icon-512.png` are uploaded.** The learning data is embedded in `index.html`. Upload the three missing files to the repository root and enable GitHub Pages under Settings > Pages > Deploy from a branch > main / (root).

Once published, open the GitHub Pages HTTPS URL in iPad Safari, then Share > Add to Home Screen. Load online once, then test airplane mode. Back up learning data regularly. Not affiliated with ERB/ISEE. Question families are template-generated and not a standardized test.
